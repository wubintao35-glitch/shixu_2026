# 结构化需求文档（PRD）

## 项目概述
- **项目名称**：GestureSnake 3D（手势控制3D贪吃蛇）
- **平台**：Web网页应用（PC浏览器）
- **核心玩法**：通过摄像头捕捉食指位置，实时控制3D蛇在游戏区域内移动、吃食物、避免撞到自己

## 技术栈
- **前端**：HTML5 + Three.js（3D渲染）+ MediaPipe Hands（手势识别）
- **后端**：无（纯前端单机版）

## 视觉风格参考：八方旅人（Octopath Traveler）HD-2D

本项目采用**HD-2D**视觉风格——将复古像素艺术与现代化3D渲染技术融合，营造独特的"像素油画"质感。

### 核心视觉特征

| 特征 | 实现方式 | 游戏内体现 |
|------|----------|-----------|
| **像素基底** | 所有物体采用低分辨率像素纹理（16×16 ~ 32×32） | 蛇身、食物、地面网格均为块状像素风格 |
| **3D体积光影** | Three.js 实时光照 + 法线贴图 | 蛇身投射动态阴影，食物自发光并照亮周围像素地面 |
| **景深模糊** | 后处理 Bokeh/Depth of Field | 游戏区域边缘适度虚化，聚焦中央游玩区域 |
| **戏剧化光照** | 高对比度定向光 + 环境光遮蔽（AO） | 暗角处理，蛇头附近有较强的点光源跟随 |
| **粒子氛围** | Three.js Points/Sprite 粒子系统 | 背景漂浮光尘，食物附近有上升的光粒 |
| **复古色调** | 高饱和度但偏暖/冷的调色板 | 主色：深靛蓝（背景）、金琥珀（食物光）、暗紫红（蛇身） |

### 具体元素设计

**蛇（Snake）**
- 身体由立方体像素块拼接，每节有明显"体素"感
- 材质：哑光像素纹理，边缘有轻微高光勾勒体积
- 特效：移动时身后拖曳淡淡的光尘粒子

**食物**
- 能量球：悬浮的像素球体，中心强光源 + 外围像素光环脉动呼吸
- 拾取时爆发一圈向外扩散的像素冲击波

**场景与背景**
- 地面：大块的像素方砖拼贴，接缝处有细微的AO阴影
- 地图边界：可见的像素矮墙或光带标识区域边缘，超出边界为暗色雾气
- 背景层：极远景的像素山峦剪影，配合视差滚动

**UI 界面**
- 字体：像素字体（如 "Press Start 2P"）
- 面板：带像素边框的半透明暗色面板
- 得分：复古数字计数器，变化时有弹跳缩放动画

### 技术实现要点
- 使用 Three.js 的 `NearestFilter` 纹理过滤保持像素锐利不模糊
- 开启 `toneMapping`（ACESFilmic）增强光影戏剧感
- 后期处理链：Bloom（辉光）→ DOF（景深）→ Vignette（暗角）

## 核心机制

### 1. 手势控制
- 使用MediaPipe Hands检测21个手部关键点
- 取食指指尖（landmark 8）坐标
- 摄像头预览区域镜像显示
- 食指指尖坐标实时映射到游戏区域对应位置
- 蛇头平滑跟随目标位置移动（360度无限转向）

### 2. 3D渲染与相机
- **视角**：3D透视视角（Perspective Camera），略带倾斜角度俯瞰游戏区域
- **蛇运动**：仅在 X、Y 平面移动，Z 轴高度固定（贴地爬行）
- **镜头跟随**：相机始终跟随蛇头位置移动，保持蛇在画面中央
- **蛇**：3D立体像素块拼接，有厚度、有体积感
- **食物**：3D像素球体，带自发光和呼吸动画
- **背景**：HD-2D风格场景（像素地面 + 远景剪影 + 粒子光尘）

### 3. 地图与碰撞规则
- **地图大小**：固定矩形区域，边长约为初始蛇身长度的 8 倍
- **边界碰撞**：蛇头碰到地图边缘 → 游戏结束
- **自碰撞**：蛇头碰到自身身体 → 游戏结束

### 4. 食物系统
- 能量球：随机位置生成，拾取后得分 + 蛇身变长

### 5. 难度递增
- 蛇的基础速度随得分增加而提升
- 速度曲线：每得50分提升一个速度等级

## 界面结构

### 开始界面
- 显示游戏标题 + 3D蛇的动画展示
- "开始游戏"按钮

### 主游戏界面
- **左侧（70%宽度）**：游戏区域（3D渲染画布）
- **右侧上方**：摄像头预览窗口（小窗，显示MediaPipe手部追踪骨架）
- **右侧下方**：得分统计区域（当前得分、速度倍率）

### 游戏结束界面
- 显示最终得分
- 显示本次游戏统计（存活时间、吃到食物数）
- "再来一局"按钮
- "返回主界面"按钮

## 游戏流程

```
打开网页
  │
  ├─ 显示开始界面
  │
  ├─ 点击"开始游戏"
  │
  ├─ 进入主游戏界面
  │
  ├─ 游戏结束
  │     │
  │     ├─ 显示最终得分 + 本次统计
  │
  └─ 点击"再来一局" 或 "返回主界面"
```
